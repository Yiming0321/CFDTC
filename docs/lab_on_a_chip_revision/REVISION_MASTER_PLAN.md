# Lab on a Chip 投稿修改总方案

> 工作分支：`lab-on-a-chip-revision`  
> 目标稿型：Lab on a Chip Full Paper  
> 当前定位：由“多种生物体系应用展示”重构为“内部参考、计算校正与闭环自适应实验相结合的微流控量热平台”

## 1. 本轮重构的核心决定

### 1.1 新的论文中心问题

固定间隔的连续流量热扫描会在平台区消耗大量时间和试剂，同时可能在热力学转折区缺少足够分辨率。本稿拟回答：

> 能否将可编程微流控组分调节、在线热功率重构与顺序实验决策结合，使连续流量热系统根据已获得的热信息自主选择后续组成条件，并以更少的测量点、时间和试剂完成热力学转折及参数的定量映射？

### 1.2 新的技术主线

```text
可编程微流控组成控制
        ↓
差分热电信号采集
        ↓
内部电功率参考与计算校正
        ↓
在线稳态判断与热功率输出
        ↓
参数拟合与不确定度评估
        ↓
下一组成点自主选择
        ↓
泵流量比自动执行
        └──────────────→ 再次测量
```

### 1.3 内容取舍原则

本稿不再以 DNA、蛋白质或光损伤机理为主要科学贡献。原因不是这些数据完全无价值，而是其可靠解释需要额外的生物物理和正交结构表征，容易使论文偏离当前最强的工程技术主线。

| 现有内容 | 新稿处理 | 说明 |
|---|---|---|
| CFDTC 芯片、双通道差分热电检测 | 主文保留 | 平台基础 |
| 薄膜加热器内部参考 | 主文保留并强化 | 由离线训练热源提升为主动自检/校准部件 |
| 多通道同步采集与计算校正 | 主文保留，但重新验证 | 需修复数据划分、在线因果处理和代码/论文一致性 |
| 表面活性剂胶束化 | 主文核心应用 | 适合作为非生物、可重复、可自动扫描的模型体系 |
| 闭环自适应采样（原 6.txt） | 升级为主文核心结果 | 取代 DNA 两章成为工程创新高潮 |
| Trypsin–BAEE 与抑制实验 | 本稿删除 | 避免蛋白活性、吸附和动力学机理争议 |
| ctDNA–EB 结合 | 本稿删除 | 删除光损伤主线后不再必要 |
| DNA–spermine 凝聚 | 本稿删除 | 缺少结构正交验证 |

## 2. 推荐论文定位与题目

### 2.1 推荐定位

**Internally referenced, computationally corrected, closed-loop adaptive microfluidic calorimetry**

论文应强调的不是“应用了机器学习”，而是形成了可验证的系统级能力：

1. 微流控平台可编程访问任意组成点；
2. 内部参考与计算校正提供稳定热功率读出；
3. 在线算法依据已有数据决定下一实验条件；
4. 泵系统自动执行并继续采集；
5. 以参数精度、点数、时间和试剂消耗评价闭环价值。

### 2.2 暂定题目

首选：

> **Closed-loop adaptive microfluidic calorimetry with internally referenced computational sensing**

备选：

> **An internally referenced microfluidic calorimeter for closed-loop thermodynamic mapping**

> **Computationally corrected microfluidic calorimetry enables adaptive mapping of thermodynamic transitions**

暂不在题目中使用 `edge–cloud`、`open environment`、`physics-informed` 或 `autonomous experimentation`。只有当相关架构、扰动实验、物理模型和全自动运行均得到直接验证后，再决定是否采用这些高强度术语。

## 3. 新的主文结构

### 3.1 Introduction

建议四段完成：

1. 连续流微量热中的热泄漏、漂移、流体携热和弱信号定量问题；
2. 固定均匀扫描在平台区低效、转折区分辨率不足的问题；
3. 微流控可编程组成控制与在线量热结合后具备闭环实验的条件；
4. 本工作的三项贡献：内部参考量热平台、计算功率重构、闭环自适应热力学映射。

### 3.2 Results

#### Result 1. Internally referenced microfluidic calorimetry platform

- 芯片和双通道结构；
- 传感器、加热器和恒温块的相对位置；
- 泵和组成控制；
- 混合表征；
- 停留时间分布；
- 原始多通道数据。

#### Result 2. Metrological validation and computational reconstruction

- 电加热标定；
- 化学热标定；
- 因果在线信号流程；
- 分功率区间误差；
- LoB、LoD、LoQ；
- 流量、温度、流体热物性、日期和芯片影响；
- 独立测试集结果；
- 内部参考脉冲自检。

#### Result 3. Continuous thermodynamic mapping of surfactant micellization

推荐主文选择三类代表体系：

- SDBS：强放热、转折清晰，用于算法开发；
- SDS 或 CTAB/DTAB：不同 CMC 区间；
- TX-100：吸热和较弱信号，用于检验符号及低信号适用性。

报告 CMC、ΔHmic、重复性、同条件参考结果、每次扫描的实际时间和试剂量。

#### Result 4. Closed-loop adaptive composition selection

将原 6.txt 的“探索—加密—收敛”提升为核心结果，必须展示：

- 实际闭环架构；
- 在线因果数据处理；
- 每轮已获得数据；
- 下一浓度点推荐；
- 泵流量指令；
- 浓度切换及稳态判断；
- CMC 与 ΔHmic 随迭代收敛；
- 自动停止；
- 决策日志和真实时间线。

#### Result 5. Generalization and resource-efficiency analysis

比较：

1. 密集均匀扫描；
2. 与自适应策略相同点数的粗均匀扫描；
3. 真实闭环自适应扫描。

从两种公平约束评价：

- 相同点数下的参数准确度；
- 相同目标准确度下的点数、时间和试剂消耗。

### 3.3 Discussion

集中回答：

- 微流控为什么使闭环组成选择成为可能；
- 相比固定扫描新增了什么实验能力；
- 内部电参考能解决什么、不能替代什么；
- 模型在流量、流体和芯片变化时的适用范围；
- 何时需要重新标定；
- 当前方法是一维组成空间的自主选择，而非完整 self-driving laboratory；
- 后续如何扩展到温度、停留时间和多目标实验空间。

## 5. 原 6.txt 的保留与修订要求

### 5.1 可以保留的核心

- Explore–Refine–Converge 三阶段逻辑；
- 平台区稀疏、转折区加密的基本思想；
- SDBS 作为算法开发体系；
- “感知—分析—决策—执行”闭环；
- 当前草稿中报告的误差下降和时间节省，可作为待复核的初步结果。

### 5.2 必须重做或补充

1. 证明自适应点来自独立真实闭环运行，而不是从密集曲线事后抽取；
2. 所有在线决策只使用当时已获得的数据；
3. 在线流程不得使用前向—反向零相位滤波；
4. 明确定义 Explore、Refine 和 Converge 的数学规则；
5. 给出停止条件、最大点数、浓度边界和失败处理；
6. 记录全部决策时间、拟合参数、推荐点和泵命令；
7. 至少进行 3 次独立完整闭环重复；
8. 在 SDBS 上冻结算法后，迁移到至少两种不同曲线形态的表面活性剂；
9. 分别报告 CMC 误差、ΔHmic 误差和曲线 RMSE，不使用含义模糊的单一“拟合相对误差”；
10. 用真实系统日志核算总时间，不以减少点数直接代替时间缩短；
11. 将当前“精度提升 41.56%”改为“相对误差降低 41.56%，绝对降低 2.51 个百分点”，前提是原始数据复核一致；
12. 58.20% 的时间缩短仅在包含稳态等待、置换、计算和决策的实际日志支持时保留。

## 7. 术语边界

| 暂不直接使用的表述 | 推荐表述 |
|---|---|
| open environment | non-vacuum, non-hermetic, thermostated benchtop conditions |
| physics-informed machine learning | physics-guided calibration / computational reconstruction，直到灰箱物理模型完成 |
| real-time | online，仅在因果算法和延迟实测后使用 real-time |
| autonomous experimentation | autonomous selection of subsequent composition setpoints |
| self-driving laboratory | 不使用 |
| edge–cloud | 若实际为本地控制器与工作站，使用 distributed edge–host architecture |
| ground truth power | controlled electrical reference input |
| 100 nW–1 mW with <3% error | 根据分区误差和 LoQ 重写 |
